# Front-end WeWeb

Le front est construit dans **WeWeb** (outil no-code) : il n'y a pas de code source à versionner. Les deux applications appellent Supabase (Auth, PostgREST, RPC, Storage, Edge Functions) avec le JWT de l'utilisateur connecté.

## PLOMI mandataire (gestionnaires)
Current_drop (carte des interventions), Liste_drop, Mandates_creation, détails_mandats, Attribution_manuelle (+ popup PLO), Liste_experts, Détails_expert, Expert_création, Liste_creation, KPIs, Recrutement_experts, Fiche_recrutement, Archives, Login, sign_up.

## PLOMI expert
Home (carte + mandats), Lancement mandat, formulaires RDF / RDFS, Synthèse, Aperçu rapport, Capture / Éditeur de médias, Archives, Détails d'archive, Profil, Modification du profil, Log in.

## Charte
Fond gris très clair, cartes blanches (bordure grise, rayon 12 px, ombre légère), couleur principale bleu marine `#1e3a8a`, boutons principal / secondaire / suppression identiques dans les deux apps.
